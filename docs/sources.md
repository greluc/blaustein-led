# Sources

Every source the documents in this folder rely on, with what it gave. All of them were opened on
2026-11-19 unless a row says otherwise. A search result snippet never counts as a source: a page is
listed here only if it was opened and read. Prices and availability are as shown on the day the page
was opened.

- **Confirmed** means the source supports a statement the plan already made.
- **Corrected** means the plan said something else before and was changed.
- A statement no source could settle is listed under [Unverified](#unverified) with what was tried.
- Pages that could not be read are listed under [Not readable](#not-readable).

Copies of the downloaded PDFs and building instructions are kept outside the repository, in the
local folder `reference/` of the main checkout. They are under third-party copyright and are never
committed; `reference/INDEX.md` maps each file to its source.

## Updating through USB

| Source | What it gave |
| --- | --- |

| [`usb_reset.c`](https://github.com/raspberrypi/pico-sdk/blob/2.3.1/src/rp2_common/pico_usb_reset/usb_reset.c), pico-sdk 2.3.1 | The request is accepted when `wIndex` is the interface number. For BOOTSEL, bits 0 and 1 of `wValue` are the boot ROM's mask of interfaces to disable; bit 8 says an activity LED pin is given, bit 7 that it is active low, bits 9 to 15 hold the pin. | [`stdio_usb_descriptors.c`](https://github.com/raspberrypi/pico-sdk/blob/2.3.1/src/rp2_common/pico_stdio_usb/stdio_usb_descriptors.c), pico-sdk 2.3.1 | Vendor ID `0x2E8A`, product ID `0x0009` on the RP2350. `bcdUSB` is `0x0210` with the Microsoft OS 2.0 descriptor and has to be `0x0200` without it |
